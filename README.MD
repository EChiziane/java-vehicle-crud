# Vehicle CRUD Project

Este é um projeto de estudo desenvolvido para praticar a implementação de um CRUD simples usando Java Spring Boot 3. O objetivo principal é aplicar boas práticas de **Clean Code** e aprender mais sobre a criação e hospedagem de APIs RESTful.

---

## 🛠 Tecnologias Utilizadas

- **Java**: Linguagem principal para o backend.
- **Spring Boot 3**: Framework usado para desenvolver APIs RESTful.
- **Git e GitHub**: Controle de versão e armazenamento do código fonte.
- **H2 Database** (ou outro banco local): Banco de dados embutido para armazenamento de informações.
- **Servidor Local**: O projeto foi configurado para rodar localmente, simulando um ambiente de produção simples.

---

## 🎯 Objetivo

- **Aprendizado**: Melhorar minhas habilidades com **Java**, **Spring Boot** e **Clean Code**.
- **Prática**: Implementar um CRUD com padrões modernos e boas práticas.
- **Deploy Local**: Entender como hospedar e acessar a aplicação em um servidor local.

---

## 🚀 Funcionalidades

1. **CRUD de Veículos**:
    - Criar um veículo.
    - Buscar todos os veículos.
    - Buscar veículo por ID.
    - Atualizar veículo existente.
    - Deletar veículo por ID.

2. **Clean Code**:
    - Código organizado e legível.
    - Utilização de boas práticas no design das classes e métodos.

3. **API RESTful**:
    - Endpoints bem definidos para operações CRUD.
